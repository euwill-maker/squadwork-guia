Antes de começar

⏱ 2 min de leitura

O Squadwork é um time de agentes de IA que roda no seu próprio computador. Pra isso funcionar, ele precisa de duas "peças de base" — a gente instala juntos nos próximos passos. Você vai precisar de:

CONTA DE IA
Claude Pro
~US$ 20/mês · é o "cérebro" dos agentes
TEMPO
~25 minutos
só na primeira vez
💡
Não precisa saber programar. Você só vai copiar comandos e clicar em "instalar". Se travar em qualquer ponto, use o botão verde no canto pra chamar no WhatsApp.
✓
Pronto pra começar? Marque este passo e vamos lá.
1✓

Instalar o Node.js

⏱ ~4 min

O Node.js é o motor que faz o Squadwork rodar. É grátis e a instalação é igual a instalar qualquer programa.

1. Acesse nodejs.org e baixe a versão LTS (escolha o instalador macOS — arquivo .pkg)(escolha o instalador Windows — arquivo .msi).

2. Abra o arquivo baixado e clique em Avançar / Continuar até o fim (pode deixar tudo no padrão).

3. Pra conferir se deu certo, abra o terminal:

  • Aperte Cmd + Espaço, digite Terminal e tecle Enter.
  • Aperte a tecla Windows, digite PowerShell e tecle Enter.

Cole este comando e tecle Enter:

node -v
✓
Deu certo se aparecer algo como v20.x.x ou maior. Se apareceu um número, está instalado!
⚠️ Deu erro ou "comando não encontrado"? +
Feche o terminal e abra de novo (ele precisa reiniciar pra reconhecer o Node).Feche o PowerShell e abra de novo. Se ainda assim não funcionar, reinicie o computador — no Windows às vezes é necessário. Depois rode node -v de novo. Continua dando erro? Chama no WhatsApp que a gente resolve junto.
2✓

Instalar o Claude Code

⏱ ~5 min

O Claude Code é onde os agentes vão trabalhar. Com o terminal ainda aberto, cole o comando:

npm install -g @anthropic-ai/claude-code

Espere terminar (pode levar 1-2 minutos). Depois, inicie o Claude Code:

claude

Na primeira vez ele vai pedir pra você entrar na sua conta. Vai abrir o navegador — faça login (ou crie sua conta Claude Pro) e autorize.

🔑
Ainda não tem a assinatura? Crie em claude.ai → escolha o plano Pro. É a conta que dá "cérebro" aos seus agentes.
✓
Deu certo se o Claude Code abrir e mostrar a tela de conversa dentro do terminal. Pode escrever /help pra testar e depois fechar com /exit.
⚠️ "npm não encontrado" ou erro de permissão? +
"npm não encontrado" = o Node não foi instalado (volte ao Passo 1). Erro de permissão no Mac? Cole:
sudo npm install -g @anthropic-ai/claude-code
e digite a senha do seu Mac (ela não aparece na tela enquanto você digita — é normal).No Windows, abra o PowerShell como administrador (clique com o botão direito no PowerShell → "Executar como administrador") e rode o comando de novo.
3✓

Criar a pasta do seu projeto

⏱ ~2 min

O Squadwork mora dentro de uma pasta no seu computador. Vamos criar uma e abrir o terminal exatamente nela.

No Mac: abra o Finder, vá em Documentos, crie uma pasta nova chamada squadwork. Clique com o botão direito nela → "Novo Terminal na Pasta".

No Windows: abra o Explorador de Arquivos, vá em Documentos, crie uma pasta nova chamada squadwork. Abra ela, clique em um espaço vazio com o botão direito → "Abrir no Terminal".

📁
Não achou a opção de abrir o terminal na pasta? Sem problema — cole no terminal o comando abaixo (ele cria e entra na pasta de uma vez):
mkdir -p ~/Documents/squadwork && cd ~/Documents/squadwork
mkdir $HOME\Documents\squadwork; cd $HOME\Documents\squadwork
✓
Deu certo se o caminho que aparece no terminal terminar com squadwork.
4✓

Instalar o Squadwork

⏱ ~3 min

Agora a parte mágica. Com o terminal aberto dentro da pasta squadwork, cole:

npx opensquad init

Ele vai fazer 3 perguntas simples — responda com as setas do teclado e Enter:

  • Idioma: escolha Português (Brasil)
  • IDE: marque Claude Code (use a barra de espaço pra marcar, depois Enter)
  • Seu nome: digite seu primeiro nome
✓
Deu certo se aparecer uma mensagem de sucesso e a pasta _opensquad for criada dentro do seu projeto.
⚠️ Pediu pra instalar o pacote (digitar "y")? +
É normal na primeira vez o npx perguntar se pode baixar o opensquad. Digite y e tecle Enter.
5✓

Abrir o Claude Code e liberar as ferramentas

⏱ ~3 min

Ainda no terminal (dentro da pasta squadwork), inicie o Claude Code:

claude

Na primeira vez, o Claude Code vai perguntar se pode confiar nesta pasta e se pode usar as ferramentas extras (os "MCPs": navegador e Canva). Responda sim / yes pra tudo — são elas que deixam os agentes postarem e desenharem por você.

🧩
Essas ferramentas são o que diferencia o Squadwork de um chat comum: é o que permite abrir o navegador de verdade, mexer em arquivos e publicar nas redes.
✓
Deu certo se o Claude Code abrir já dentro da sua pasta squadwork, pronto pra receber comandos.
⚠️ Apareceu erro de navegador "já em uso"? +
Feche todas as janelas do Chrome e tente de novo. Esse navegador é usado pelos agentes pra trabalhar.
6✓

Conectar suas contas

⏱ ~3 min

Você só precisa fazer isso uma vez, e só quando um squad for de fato publicar em algum lugar (ex: Instagram). Quando isso acontecer, o Squadwork vai abrir o navegador e pedir pra você fazer login manualmente na sua conta.

Depois do login, ele pergunta se quer salvar a sessão. Responda sim — assim ele lembra do seu login nas próximas vezes e você não precisa repetir.

🔒
Seus logins ficam salvos só no seu computador (pasta privada, nunca enviada pra ninguém). Pra remover, é só apagar a pasta _opensquad/_browser_profile.
✓
Tudo certo! Você pode pular isso por agora e fazer quando rodar seu primeiro squad de publicação.
7✓

Rodar seu primeiro squad 🚀

⏱ ~3 min

Chegou a hora. Dentro do Claude Code, é só digitar:

/opensquad

Vai abrir o menu do Squadwork. A partir daí você pode criar um squad novo descrevendo o que quer, em português, do seu jeito. Exemplo pra testar:

/opensquad crie um squad que gera um carrossel de Instagram sobre um tema que eu escolher

O Arquiteto vai te fazer algumas perguntas, montar o time e pedir sua aprovação antes de executar. É só seguir o que ele pedir.

✓
Parabéns! Se o menu do Squadwork apareceu, está tudo funcionando. 🎉
8✓

Ver seu time trabalhando ao vivo 🏢

⏱ ~6 min · opcional

Bônus: o Pixel Agents transforma seu time num escritório em pixel art, onde cada agente vira um personagem que anda até a mesa e trabalha em tempo real. É opcional — o Squadwork funciona perfeitamente sem ele.

1. Instale o VS Code (grátis): acesse code.visualstudio.com e clique em Download for Mac. Abra o .zip baixado e arraste o "Visual Studio Code" pra pasta Aplicativos.Download for Windows. Rode o instalador e clique em "Próximo" até o fim.

2. Abra o VS Code, clique no ícone de Extensões na barra lateral (os 4 quadradinhos), busque Pixel Agents e clique em Instalar (autor: pablodelucca).

3. No VS Code, vá em Arquivo → Abrir Pasta e escolha a sua pasta squadwork.

4. Aperte CmdCtrl + Shift + P, digite o comando abaixo e tecle Enter:

Pixel Agents: Show Panel

5. Agora mande qualquer tarefa pro Claude Code. O agente vai aparecer no escritório — você vai ver ele caminhar até a mesa e começar a trabalhar.

🎬
Cada Claude Code aberto vira um personagem diferente no escritório. Abra 3 e você tem 3 agentes trabalhando ao mesmo tempo.
✓
Deu certo se o painel do Pixel Agents abrir com o escritório e seu agente aparecer. Se ele estiver parado, é porque o Claude Code está esperando — manda qualquer tarefa pra ele se mexer.
⚠️ Mac: "o app não pode ser aberto"? +
Vá em Ajustes do Sistema → Privacidade e Segurança e clique em "Abrir assim mesmo". Ainda travou? Chama no WhatsApp.

Criar sua conta no GitHub

⏱ ~8 min · só na primeira vez

O GitHub é onde os sites ficam guardados e publicados. Você precisa de 3 coisas: a conta, o Git e o GitHub CLI (o programa que deixa o Claude Code publicar por você).

1. Crie sua conta grátis em github.com/signup. Escolha bem o nome de usuário: ele aparece no endereço dos sites (seunome.github.io).

2. Instale o Git:

  • No Terminal, cole git --version. Se o Mac oferecer pra instalar as "ferramentas de linha de comando", clique em Instalar e espere.
  • Baixe em git-scm.com e instale clicando em "Next" até o fim (pode deixar tudo no padrão).

3. Instale o GitHub CLI: baixe em cli.github.com (arquivo .pkg do macOS)(arquivo .msi do Windows) e instale.

4. Feche e abra o terminal de novo, e conecte sua conta:

gh auth login

Responda com as setas e Enter: GitHub.com → HTTPS → Yes → Login with a web browser. Ele mostra um código de 8 letras, abre o navegador e você cola o código lá.

✓
Deu certo se aparecer Logged in as seunome.
⚠️ "gh: comando não encontrado"? +
Feche o terminal e abra de novo — ele precisa reiniciar pra enxergar o programa novo. No Windows, se não resolver, reinicie o computador.
10✓

Pedir o site pro Claude Code

⏱ ~10 min

1. Junte o material do cliente: logo, fotos, cores, serviços, endereço e WhatsApp. Coloque os arquivos numa pasta sites/nome-do-cliente dentro da sua pasta squadwork.

2. Abra o Claude Code na pasta squadwork (claude), copie o pedido abaixo e troque o que está entre colchetes:

Crie um site de uma página só para [NOME DO CLIENTE], que [o que a empresa faz] em [cidade]. Salve em sites/[nome-do-cliente]/index.html, tudo num arquivo só. Faça pensando primeiro no celular. Seções: topo com uma chamada forte, serviços, sobre, depoimentos, perguntas frequentes e contato. Cores: [cores da marca]. Use o logo e as fotos que estão na pasta. WhatsApp: [55 + DDD + número]. Coloque um botão flutuante de WhatsApp e um formulário de contato que abre o WhatsApp com a mensagem pronta.

3. Quando ele terminar, peça: "abra o site no navegador". Não gostou de algo? Peça do seu jeito: "deixa o topo mais escuro", "troca a foto do topo", "aumenta o botão".

💡
Quanto mais informação real do cliente, melhor fica o site. Sem material, a IA inventa texto genérico — e site genérico não vende.
✓
Deu certo se o site abriu no navegador com o nome, as cores e o WhatsApp do cliente.
11✓

Ajustar pro celular 📱

⏱ ~5 min · nunca pule

Quase todo cliente que vem de anúncio ou do Instagram abre o site no celular. Se ficar ruim no celular, o site não funciona — não importa o quão bonito esteja no computador.

1. Com o site aberto no Chrome, aperte Cmd + Option + IF12 e depois CmdCtrl + Shift + M. A tela vira um celular. Escolha iPhone lá em cima.

2. Confira:

  • Dá pra ler o texto sem dar zoom?
  • Os botões são grandes o suficiente pro dedo?
  • Nada vaza pro lado (a tela não arrasta na horizontal)?
  • O botão do WhatsApp aparece sem precisar rolar muito?

3. Achou problema? Peça pro Claude Code revisar:

Revise o site sites/[nome-do-cliente] no tamanho de celular (390px de largura). Corrija qualquer texto pequeno, botão difícil de tocar ou coisa vazando pro lado.
✓
Deu certo se você conseguir navegar o site inteiro no modo celular sem dar zoom e sem a tela arrastar pro lado.
12✓

Testar o formulário que manda pro WhatsApp

⏱ ~3 min

O formulário não precisa de servidor nem de mensalidade: quando a pessoa clica em enviar, o site abre o WhatsApp do cliente com a mensagem já escrita (nome, telefone e o que ela quer). Ela só aperta enviar.

1. Preencha o formulário com dados de teste e clique em enviar.

2. Confira se abriu a conversa com o número certo e se a mensagem chegou completa.

Se o site ainda não tem formulário, peça:

Adicione um formulário de contato com nome, telefone e mensagem. Ao enviar, abra o WhatsApp [55 + DDD + número] com a mensagem pronta, organizada com os dados preenchidos.
✓
Deu certo se o WhatsApp abriu no número do cliente com a mensagem pronta.
⚠️ Abriu "número inválido" no WhatsApp? +
O número tem que estar no formato 55 + DDD + número, só números, sem espaço nem traço. Exemplo: 5511999998888. Peça pro Claude Code corrigir.
13✓

Publicar grátis no GitHub Pages 🚀

⏱ ~3 min

Agora o site vai pra internet. Você não precisa saber Git: o Claude Code faz tudo. Cole:

Publique a pasta sites/[nome-do-cliente] no GitHub Pages: crie um repositório público chamado [nome-do-cliente] na minha conta, envie os arquivos, ative o GitHub Pages na branch main e me mande o link quando estiver no ar.

Em 1 a 2 minutos o site fica no ar num endereço assim: seunome.github.io/nome-do-cliente. Já dá pra mandar pro cliente aprovar.

🔁
Pra atualizar depois: peça a mudança e diga "publique a atualização". Em 1 minuto o site no ar muda sozinho.
✓
Deu certo se o link abrir o site no seu celular (fora do Wi-Fi, pra ter certeza).
⚠️ O link deu erro 404? +
Na primeira publicação o GitHub pode levar até 10 minutos. Espere um pouco e atualize a página. Continuou? Peça ao Claude Code: "confira por que o GitHub Pages do [nome-do-cliente] não está no ar".
14✓

Domínio próprio no Registro.br + cadeado 🔒

⏱ ~15 min + espera do DNS

Pra trocar o seunome.github.io/... por nomedocliente.com.br, com o cadeado de site seguro (HTTPS).

1. Registre o domínio em registro.br (~R$ 40/ano). O ideal é registrar no CPF/CNPJ do cliente: o domínio é dele.

2. No Registro.br, abra o domínio → DNS → Editar zona (se pedir, ative o modo avançado). Crie estes registros:

TipoNomeValor
A(vazio)185.199.108.153
A(vazio)185.199.109.153
A(vazio)185.199.110.153
A(vazio)185.199.111.153
CNAMEwwwseunome.github.io

3. Peça ao Claude Code:

Configure o domínio [nomedocliente.com.br] no GitHub Pages do site [nome-do-cliente]. Depois confira se o DNS já está apontando certo.

4. Espere o DNS espalhar (de minutos até algumas horas). Quando o site abrir pelo domínio, peça: "ative o Enforce HTTPS do site [nome-do-cliente]". O cadeado pode levar até 24h pra ficar pronto.

⚠️
O cliente já tem e-mail nesse domínio (ex: contato@nomedocliente.com.br)? Antes de mexer no DNS, anote os registros MX (e TXT) que já existem e recrie eles na zona nova. Senão o e-mail dele para de funcionar.
✓
Deu certo se https://nomedocliente.com.br abrir o site com o cadeado na barra do navegador.
⚠️ O cadeado travou e não sai nunca? +
Peça ao Claude Code: "remova e adicione de novo o domínio do site [nome-do-cliente] no GitHub Pages". Isso destrava a emissão do certificado. Prefira sempre o domínio principal (com e sem www), não subdomínios.
